# Nitro Forge

A 2D HTML5 Canvas drag racing game inspired by classic pixel art tuning games. 

## Features
* Buy and customize vehicles.
* Upgrade engines, tires, intake, and nitrous.
* Race opponents in a 1/4 mile drag strip.
* Perfect shift mechanics and starting tree timing.
* Progress saves automatically in your browser.

## How to Play / Install (GitHub Pages)
1. Ensure all files are in the correct directory structure:
    * `index.html` (root)
    * `README.md` (root)
    * `/css/style.css`
    * `/js/data.js`
    * `/js/car.js`
    * `/js/audio.js`
    * `/js/garage.js`
    * `/js/ui.js`
    * `/js/race.js`
    * `/js/main.js`
2. Push this repository to your GitHub account.
3. Go to the repository **Settings** -> **Pages**.
4. Set the Source to the branch you pushed to (usually `main` or `master`) and save.
5. GitHub will generate a URL where you can play the game live in your browser!
